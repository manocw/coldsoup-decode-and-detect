# Public release

This repository is the public release of team coldsoup's entry to Decode & Detect: The XRPL AI Hack
(24 October 2026), under the MIT licence (see `LICENSE`).

- The history holds the team's commits from 24 October with their original dates. Commit `75e8365` has
  exactly the files of the submitted commit `579d297`; commit IDs differ because the history was exported
  to this repository.
- The latest commit adds the remaining files from the submitted code ZIP: the slides, `SUBMISSION_INFO.txt`,
  the final predictions (`submissions/b1_rank_v7_v12.csv`) and the AI-assistance records in `ai_assistance/`.
- The raw Claude Code session transcript (`ai_assistance/claude_code_session_transcript.zip` in the ZIP) is not
  published here because it contains personal information. The organisers have it in the submitted ZIP.
- The final predictions were generated on Windows 11, not on Linux as the README states. Linux gives slightly
  different predictions from the same code; see the verification pack sent to the organisers.
